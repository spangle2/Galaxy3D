# Galaxy3D - Solar System Simulation

A 3D interactive solar system simulation that shows the planets orbiting around the sun. Built with Three.js.

## Features
- Accurate relative planet sizes and orbital distances
- Realistic orbital speeds
- Interactive camera controls (orbit, zoom)
- Star background

## How to Use
1. Open the `index.html` file in a web browser
2. Use mouse to orbit around the solar system
3. Scroll to zoom in/out

## Technologies
- Three.js for 3D rendering
- OrbitControls for camera manipulation
